ID: T-002
Цель: Перевести backend на PostgreSQL: URL БД из env, драйвер psycopg.

Контекст:
- URL БД захардкожен в `backend/app/database.py:7-18`: `sqlite:///./database.db`, `create_engine(..., connect_args={"check_same_thread": False})`.
- Таблицы уже создаются `Base.metadata.create_all(bind=engine)` при старте в `backend/main.py:15-19`. Это не менять.
- `load_dotenv()` вызывается в `backend/main.py:1-4`.
- `backend/migrate_db.py` одноразовый SQLite-скрипт, приложением не используется. Не трогать.
- Данные не переносим: БД стартует пустой.
- Модели (`backend/app/models.py`) используют Boolean, DateTime без timezone, JSON, Enum (`EventType`, `ControlPointType`).

Файлы:
- изменить: `backend/app/database.py`
- изменить: `backend/requirements.txt`

Делать:
1. В `database.py` читать `DATABASE_URL` из окружения. Формат `postgresql+psycopg://user:pass@host:5432/dbname`. Если переменная не задана, падать при импорте с `RuntimeError("DATABASE_URL is not set")`. Дефолта на SQLite не оставлять.
2. `database.py` читается при импорте. Проверить порядок импортов в `main.py`: `load_dotenv()` должен отработать до импорта `database`. Если гарантии нет, добавить `load_dotenv()` в начало `database.py`.
3. Убрать `connect_args`.
4. В `requirements.txt` добавить `psycopg[binary]` с точной версией (`==`, актуальная стабильная 3.x). Проверить, есть ли `python-dotenv`, если нет, добавить так же.

Не трогать: `models.py`, роуты, `main.py` (кроме случая из п.2, о нём сообщить в ответе), `migrate_db.py`, фронтенд, Docker-файлы.

Готово, когда:
- без `DATABASE_URL` приложение не стартует, в ошибке названа переменная;
- с `DATABASE_URL` на локальный Postgres 16 приложение стартует, `\dt` показывает таблицы всех моделей;
- повторный старт проходит без ошибок и не стирает данные;
- сценарий: регистрация → логин → действие, пишущее и читающее поля с JSON, DateTime, Enum и Boolean (например, сохранение/чтение событий расписания), без ошибок, строки видны в таблицах;
- `grep -rin sqlite backend/app backend/main.py backend/requirements.txt` ничего не находит;
- дифф затрагивает 2 файла.

Как проверить:
```
docker run -d --name pg-test -e POSTGRES_PASSWORD=test -e POSTGRES_DB=chronella -p 5432:5432 postgres:16
export DATABASE_URL=postgresql+psycopg://postgres:test@localhost:5432/chronella
cd backend && pip install -r requirements.txt && uvicorn main:app --port 8000
docker exec pg-test psql -U postgres -d chronella -c "\dt"
```
Перезапустить uvicorn, повторить `\dt` и убедиться, что данные на месте.

Формат ответа: дифф + вывод `\dt` + список проблем совместимости с PostgreSQL, если встретились. Исправлять только блокирующие запуск, остальное описать.
