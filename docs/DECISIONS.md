# DECISIONS

Формат: ID — решение — причина — статус (`принято` | `предложено`, ждёт Lead).

## D-001 Предмет курсовой — развёртывание
Прикладная логика Chronella не меняется. Правки кода только такие, без которых система не работает в контейнерах.
Причина: тема C курсовой, оценивается DevOps-часть.
Статус: принято.

## D-002 СУБД: PostgreSQL 16 вместо SQLite
Отдельный контейнер `db`, данные в именованном томе `pgdata`, доступ только у `backend`.
Статус: принято.

## D-003 Топология
Три контейнера в сети `chronella_net` (bridge). На хост опубликован только порт Nginx: `8080:80`. Сервисы обращаются друг к другу по именам `db`, `backend`, `frontend`.
Статус: принято.

## D-004 Конфигурация через env
Всё, что зависит от окружения (строка БД, JWT-секрет, Google client id/secret, CORS, пути), читается из переменных окружения. Реальный `.env` в `.gitignore`, в репозитории только `.env.example`.
Статус: принято.

## D-005 Схема БД без миграций
Таблицы создаются при старте backend через `Base.metadata.create_all()`. Alembic не вводим.
Причина: нет данных для переноса, схема стабильна, курсовая про развёртывание. Экономит ~1 ч.
Условие: T-001 подтверждает, что схема описана SQLAlchemy-моделями (A-2). Если нет, пересмотреть.
Статус: **предложено**.

## D-006 Данные из `chronella.db` не переносим
Postgres стартует пустым, пользователь регистрируется заново, расписание подтягивается из ЭИОС.
Статус: **предложено**.

## D-007 Google credentials и токены вне образа
Файлы credentials/token не копируются в образ и не коммитятся. Backend получает пути из env, файлы монтируются в контейнер как volume (read-only для credentials). `.dockerignore` их исключает.
Статус: **предложено**.

## D-008 CI/CD, миграции, мониторинг вне scope
См. «Не входит» в SCOPE.md. Возвращаться к вопросу только после сдачи курсовой.
Статус: **предложено**.

## D-009 Запуск в два шага при разработке
Сначала Postgres в Docker, backend и frontend на хосте (проверка миграции на PG отдельно от контейнеризации), затем полная контейнеризация.
Причина: локализует ошибки, не пересобирать образы десятки раз.
Статус: **предложено**.
